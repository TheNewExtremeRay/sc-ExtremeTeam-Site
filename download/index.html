Installation notes

Installation steps are documented alongside each published release, not invented in advance.

How is a release installed?

FractalScript’s original environment is a Python application, and release 1.0.0 is published above as a single .zip archive. This page does not guess at package names, commands or system requirements — each release entry carries its own verified file description, and the project’s sources remain authoritative for setup details.

What is the difference between the playground and the original environment?

The playground is this site’s browser implementation of FractalScript’s verified historical feature set, with concrete syntax bindings documented on the main site. The original environment is the project’s own Python/Pygame application. The project’s sources remain authoritative wherever they differ.

Does the Fractal VM have downloads here?

The Fractal VM is a separate register-based prototype with its own .frac program format. It is an exploration project — not a complete production-ready virtual machine — and its artifacts, if any, will be described with their own verified release entries.
